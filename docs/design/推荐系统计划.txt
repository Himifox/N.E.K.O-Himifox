7. 依赖方向

Router
  → RecommendationService
    → engine / feedback / observation / tuning
      → state
        → persistence
          → normalization / domain_models

额外约束：
- Engine 不依赖 State、Persistence 或 Router；
- Feedback 不依赖 Tuning；
- 推荐包内部模块不从包根 __init__.py 反向导入；
- State/Tuning 不自行实现 read_text、write_text、os.replace 或固定 .tmp；
- 参数使用 context，不使用 ctx。

8. 命名合同

禁止文件名：common.py、utils.py、helpers.py、misc.py、model.py、policy.py、events.py、reports.py。

禁止重新定义的模糊 helper：_clamp01、_unit、_number、_finite、_text、_clean_text、_count、_rate、_average、_mode、_delta、_snapshot、_public_state。

命名语义：
- coerce_*：尝试类型转换，失败使用默认值；
- normalize_*：把合法表示统一为标准表示；
- sanitize_*：删除或转换不允许持久化的数据；
- validate_*：返回问题，不修改输入；
- clamp_*：限制数值范围。
