# 网易云匿名点歌插件

这是一个只通过 NEKO 公开插件 SDK 接入的网易云点歌插件。它不会修改核心对话、Realtime、音乐正则或前端代码。

## 使用方式

插件首次安装时默认关闭。启用 analyzer、用户插件通道并启动本插件后，可以直接说“播放《歌名》”或“网易云播放 歌名 歌手”。现有 analyzer 会根据入口说明判断是否调用 `play_netease_music`；插件本身不监听全部消息，也不注册正则命令或 `@llm_tool`。

插件会匿名搜索最多五个结果。只要有结果与“歌名”或“歌名＋歌手”精确匹配，就默认播放搜索顺序中的第一个精确结果；完全没有精确匹配时才显示候选，不会根据包含关系或相似度擅自播放。候选目前不是可点击按钮，请使用更完整的歌名、歌手或版本再次点播。同一角色连续收到多次点歌时，以最后一次请求为准；不同角色的播放器互不影响。

## 安全与隐私

- 搜索地址固定为网易云公开搜索接口，播放地址只能由验证过的十进制歌曲 ID 构造。
- 所有实际网络请求和最终播放地址均为 HTTPS；重定向的每一跳都会校验网易云域名。
- 插件不接受模型传入播放 URL，不读取 NEKO、浏览器或系统 Cookie，不继承环境代理。
- 日志、候选和错误中不输出完整音频 URL、签名查询串、Cookie 或响应体。
- 播放动作只发送给调用上下文中的 `lanlan_name`；缺少目标会话时直接拒绝，避免广播到其他角色。

## 限制

MVP 只支持网易云匿名公开搜索和单曲播放，不支持登录、Cookie、会员/VIP 音源、用户歌单、泛推荐、暂停、停止、切歌、下一首或定时推歌。部分版权受限歌曲即使可以搜索到，也可能无法匿名解析和播放。

本插件的业务源码与核心音乐实现隔离，但运行时仍依赖 NEKO 的插件 SDK、analyzer、消息桥接、通用媒体播放器/代理，以及项目环境中已有的 `httpx`。它不是可脱离 NEKO 单独安装的播放器。
